## Ma manière de travailler

**Partir d’un cas réel.** Comprendre les utilisateurs, leurs fichiers et le résultat attendu avant de définir la solution.

**Construire un périmètre clair.** Préciser les contraintes, les livrables et les critères de validation ; prototyper les points incertains.

**Livrer un outil utilisable.** Prévoir l’installation, la documentation et l’accompagnement, puis faire évoluer l’outil avec les retours des équipes.
